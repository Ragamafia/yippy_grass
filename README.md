# Grass Token Farming Bot

## Описание проекта

Этот проект представляет собой автоматизированного бота для фарминга токенов криптопроекта Grass. Бот позволяет пользователям добавлять свои аккаунты и осуществлять автоматическое получение токенов через вебсокеты. Вся работа происходит в реальном времени, что обеспечивает максимально эффективное использование доступных ресурсов.
